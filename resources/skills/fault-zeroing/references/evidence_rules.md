# 证据等级和引用规范

## 证据等级

| 等级 | 含义 | 可支持的结论 |
| --- | --- | --- |
| A | 原始日志、试验记录、检测数据、设计约束原文，且来源明确 | 可支持事实判断和高置信推断 |
| B | 专家记录、会议纪要、历史案例、人工复核结论，来源明确 | 可支持中置信推断 |
| C | 间接描述、二手转述、缺少上下文的片段 | 只能作为线索，不得单独支撑根因 |
| D | 无来源假设、模型自由推断 | 只能列为待验证项 |

## 引用格式

- 文件证据：`文件: <path>`。
- 行号证据：`文件: <path>:<line>`。
- 章节证据：`文件: <path>，章节: <heading>`。
- 冲突证据：同时列出支持与反证来源，并写明冲突点。

## 遥测数值

`.dat` 遥测文件是合法证据输入，必须如实记入证据台账与资料覆盖矩阵。模型依据遥测格式文档（Telemetry Format Document）起草 Frame Layout Spec（帧布局参数）并由 parse_dat 解出的数值，默认按待验证级（pending_verification）对待，直到与格式文档样例或用户提供的参照结果互证；不新增定级流程。引用解出的数值时按引用格式给出 .dat 路径，能定位时附帧号。

## 结论约束

1. 根因结论必须至少有一条 A 或 B 级证据。
2. 只有 C/D 级证据时，结论必须标记为“待验证”；没有任何证据支持时同样只列为待验证项。
3. 概率判断必须说明依据来源；没有来源时概率字段保持为空。
4. 不得把“资料未显示异常”写成“确认无异常”，除非资料覆盖了对应验证范围。
5. 静态扫描告警单独最多只能作为 high_risk_candidate（高风险候选），不得直接写成 confirmed；必须与人工阅读交叉验证后才能升级为结论。
