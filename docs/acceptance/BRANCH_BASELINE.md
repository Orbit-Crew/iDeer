# Branch baseline decision (2026-10-26)

The authoritative delivery branch of this repository is **`develop`**.

All issue 105–111 delivery work (Server PRs #142–#145 and the coordinated
hardening in `codex/complete-issues-105-110`) is merged to and continues on
`develop`. The `main` branch has diverged (it carries an unrelated upstream
lineage); synchronizing or recreating `main` is tracked as a separate
follow-up task and is deliberately **not** part of the issue 105–111
acceptance. Release/acceptance evidence in this phase binds `develop`
commits and the Desktop repository's matching branch; nothing in this phase
is claimed against `main`.
