# 历史证据归档

> audience: maintainers, auditors, incident reviewers<br>
> status: current<br>
> owner: repository maintainers<br>
> last-verified: 2026-10-04<br>
> canonical-path: `docs/archive/README.md`

这里保存已结束的计划、审计、事故复盘、变更报告和阶段总结。归档文件保留原始结论与来源，不作为当前操作步骤或产品规范。任务从历史材料出发时，先看各登记页标注的适用时期和当前替代入口，不把归档结论当作现行依据。

现有归档分区：

- [`pr-evidence/`](pr-evidence/)：提交和验证证据。
- [`task-briefs/`](task-briefs/)：已结束任务简报。
- [`2026/`](2026/README.md)：2026 年计划、审计和阶段材料登记，主题入口见[2026 年归档索引](2026/README.md)。

后续归档目录按 `docs/archive/<year>/<topic>/` 组织。2026-07 首轮迁移只移动不删除，旧路径不保留跳转桩；此后删除或迁移归档文件前，仍须先完成全量引用扫描、内容覆盖审查和人工确认，完整规则见[2026 年归档的"归档规则"](2026/README.md#归档规则)。
