## Permissions chapter-scope adjudication

The route links `permission-model-redesign.md#2-design-principles`, `#3-角色与权限`, and `#4-浏览权限visibility-控制`. Those anchors are subsections in the Roman-numeral first chapter, `#一、权限模型与规则`. The source's implementation-state note says that this first chapter's permission rules and approval semantics remain current, and cross-checks the access rules against `backend/app/gateway/authz.py`. The same note calls the second through fifth Roman-numeral chapters DB, API, frontend, and migration design baselines. The route's phrase “第二至五章” should therefore mean chapters II–V, not subsections 2–5 in chapter I.

The qualification needs two explicit exceptions. Sections 3.7 (visibility approval API) and 3.8 (audit log API) are within chapter III, but the source note says their routes match current implementation. Treat those implementation-matching portions as current references where the task changes those endpoints. The other API design detail remains a 2026-07 baseline. Section 4 is marked unverified page by page, and section 5 records executed historical migration steps; neither should be routed as a general current implementation contract. For database, frontend, or migration work, verify against the current model, route, UI, or migration source before relying on the design text.

The Permissions route also points to current role and visibility sections in `permission-matrix.md`; that document's status note scopes those semantics as current and marks API, database, frontend, and migration sections as design baseline. The matrix itself records that tightening visibility is owner-driven and immediate, while widening requires approval. The role/approval workflow must be read from the current semantic sections and verified against current source when implementation details matter.

This resolves the chapter-label ambiguity without reclassifying the whole source document or rewriting protected content. The current [Permissions route](../agents/routes/permissions.md) remains the agent entry. The reviewer-only matrix below states which branch activates which current material.
